# RetailPulse

AI-Powered Customer Analytics & Demand Forecasting Platform.

## Structure

- `frontend/` — React + Vite UI
- `backend/` — FastAPI REST API
- `ml/` — preprocessing, forecasting, segmentation, churn and inventory ML
- `data/` — raw, processed and sample datasets
- `reports/` — generated business reports
- `docs/` — project documentation
- `docker/` — containerization files
- `tests/` — frontend, backend and ML tests

## Build Order

1. Frontend UI
2. FastAPI backend
3. Data ingestion and cleaning
4. Forecasting
5. Customer segmentation
6. Churn prediction
7. Inventory optimization
8. What-if analysis
9. Reports and monitoring
